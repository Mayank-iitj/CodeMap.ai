## 📌 Overview

**CodeMap.ai** is an intelligent developer tool designed to eliminate context-switching and accelerate code comprehension. By automatically analyzing repository structure, module dependencies, and code execution paths, CodeMap.ai renders high-level interactive diagrams and semantic maps of your project in real time.

Whether you're onboarding onto a massive legacy codebase, conducting security audits, or planning complex refactors, CodeMap.ai provides the visual clarity needed to ship with confidence.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🧠 **AI Code Analysis** | Parses ASTs and source code to derive logical relationships, entry points, and data flow. |
| 🗺️ **Interactive Visual Graph** | Zoom, pan, and filter through dynamically generated component and module dependency maps. |
| ⚡ **Lightning Fast** | Built on top of Vite and Bun for near-instant cold starts and sub-millisecond hot module replacement (HMR). |
| 🎨 **Modern Dark UI** | Clean, accessible developer experience designed with Tailwind CSS and Radix UI primitives. |
| 🛡️ **Privacy First** | Local processing options to keep your proprietary enterprise code secure. |
